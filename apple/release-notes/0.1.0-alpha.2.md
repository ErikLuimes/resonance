## Automatic updates

Resonance now keeps itself up to date.

- **Check for Updates…** in the Resonance menu looks for a new version right away.
- Resonance checks once a day by itself. Turn this off, or let it download and install updates when you quit, in Settings → Advanced → Updates.
- Every update is checked against Resonance's signing key before it's installed. Nothing about your Mac is sent.

This is the last version you need to download by hand.
