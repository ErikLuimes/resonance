## Better Sounds Like

Sounds Like finds closer matches. In testing on composers it hadn't been tuned on, nearly twice as many of its suggestions came from the same composer as the tune you're playing.

- It now looks at how each instrument is shaped, not only which waveforms and effects a tune uses.
- It also compares how tunes actually sound, using a small download made in advance. Nothing is analysed on your Mac beyond the usual scan.
- Percentages in Sounds Like are worked out differently, so they won't match what you saw before.
- Your fingerprints are rebuilt once: Resonance downloads the new set the first time you open it.

## Fixes

- Opening a tune from a nested composer folder, such as from Sounds Like, no longer shows an empty page with 0 tunes. It opens the folder the tune is listed under.
